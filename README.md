# Веб-интерфейс симуляции и мониторинга процессов энергоблока АЭС (ВВЭР-1000)

Интерактивная учебно-исследовательская платформа и SCADA-система реального времени для численного моделирования теплофизических и нейтронно-физических процессов двухконтурного ядерного энергоблока с реактором типа ВВЭР-1000 / PWR.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
Требуется Python 3.10+:
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера симуляции
```bash
python run.py
```
После запуска откройте в браузере: **`http://localhost:8000`**

### 3. Запуск автоматических тестов
```bash
python -m pytest tests/
```

## ⚙️ Архитектура системы

- **Физический движок (`backend/physics/`)**:
  - `kinetics.py`: Точечная кинетика нейтронов с 6 группами запаздывающих нейтронов ($U^{235}$), безусловно устойчивая неявная схема интегрирования и учет остаточного тепловыделения по стандарту ANS-5.1.
  - `reactivity.py`: Моделирование обратных связей по реактивности:
    - Доплеровский температурный эффект топлива ($\alpha_D = -2.6$ pcm/°C).
    - Температурный коэффициент замедлителя/теплоносителя ($\alpha_C = -32.0$ pcm/°C).
    - Дифференциальная эффективность бора и кинетика отравления ксеноном ($Xe^{135}$) и йодом ($I^{135}$).
    - S-образные кривые эффективности регулирующей рабочей 10-й группы СУЗ и глубокой подкритичности АЗ-5.
  - `thermal_hydraulics.py`:
    - 1-й контур: ТВЭЛ $\rightarrow$ оболочка $\rightarrow$ теплоноситель ($T_{гор} \approx 320^\circ$C, $T_{хол} \approx 290^\circ$C, $P_1 = 15.7$ МПа, расход 18 800 кг/с).
    - Компенсатор давления (КД): водяной объем, паровая подушка, автоматика ТЭНов, распылительный впрыск и предохранительные клапаны.
    - Парогенератор (ПГ): U-образные трубки, кипение котловой воды, генерация пара ($P_2 = 6.4$ МПа).
    - 2-й контур: Главный паропровод, паровая турбина, турбогенератор (1000 МВт эл.), конденсатор и питательные насосы (ПЭН).

- **Цикл симуляции и защита (`backend/simulation/`)**:
  - `engine.py`: Асинхронный цикл с дискретизацией 50 мс (20 Гц), регулированием скорости времени (1x, 2x, 5x) и паузой.
  - `safety_system.py`: Логика защит и блокировок (АЗ-5 при мощности $> 107\%$, периоде $< 10$ с, давлении $P_1 > 17.6$ МПа или $< 14.0$ МПа, падении уровня ПГ).

- **API и потоковая передача (`backend/api/`)**:
  - FastAPI сервер с WebSocket `/ws/telemetry` (передача 20 FPS телеметрии).
  - REST API для команд управления, сброса и инжекции отказов.

- **Операторский веб-интерфейс (`frontend/`)**:
  - **Интерактивная мнемосхема (P&ID Mimic Display)**: динамическая векторная схема энергоблока с анимацией свечения активной зоны, циркуляцией теплоносителя, вращением роторов ГЦН и турбогенератора, уровнем в КД и ПГ.
  - **Пульт оператора**: кнопка аварийной защиты реактора (**АЗ-5**) с откидным защитным колпачком, ручное и автоматическое управление группами СУЗ, тумблеры ГЦН и регуляторов.
  - **Осциллограф и тренды**: высокочастотный многоканальный самописец (мощности, давления, положение стержней).
  - **Журнал сигнализаций**: световое табло предупредительной и аварийной сигнализации с функцией квитирования.
  - **Панель инструктора (Аварийные сценарии)**:
    1. Обесточивание / отключение ГЦН-1.
    2. Разрыв главного паропровода 2 контура.
    3. Течь теплоносителя 1 контура (LOCA).
    4. Заклинивание приводов стержней СУЗ.
    5. Сброс электрической нагрузки сети / обесточивание блока.
